Quick Start & Deployment

Run locally with Docker, deploy to Kubernetes clusters, or install pre-commit git hooks in your repositories.

Launch complete 5-stage stack (API, Redis, Postgres, Qdrant, React Frontend):
# 1. Clone this repository
git clone https://github.com/motherskitchenblr2/Code-Rabbit-Alternative.git
cd Code-Rabbit-Alternative

# 2. Configure environment keys
cp .env.example .env
# Edit .env with your GitHub webhook token & LLM keys

# 3. Launch full cyberpunk stack
docker-compose up -d

# 4. Open live interactive dashboard
open http://localhost:5173
Production Kubernetes deployment via Helm or native manifests:
# Install via official Helm Chart
helm repo add gitfix https://charts.gitfix.io
helm install gitfix gitfix/gitfix \
  --namespace gitfix \
  --set github.webhookSecret=$WEBHOOK_SECRET \
  --set database.password=$DB_PASSWORD

# Or deploy native manifests in deploy/ directory
kubectl apply -f deploy/docker/
kubectl get pods -n gitfix
Prerequisites: Python 3.11+, Node 18+, Redis 7, Postgres 15:
# Backend setup
cd backend
pip install -r requirements.txt
cp .env.example .env
python -m app

# Frontend setup (in a separate terminal)
cd frontend
npm install
npm run dev
# Dashboard opens on http://localhost:5173
Instant local code review before any git commit is dispatched:
# Automatic global installation
cd scripts
python install_hooks.py

# Or install manually per repository:
cp backend/hooks/pre-commit.py .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit

# Git commits now automatically undergo AST security review!
docker-compose.yml deploy.sh Makefile
